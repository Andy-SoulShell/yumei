# C 端陪伴体验升级执行与验收记录

本清单对应 2026-10-20 用户授权的完整四阶段升级。工作在 `codex/companion-experience-upgrade` 分支进行；每批实现、测试、修复后提交。未验证的能力保持未完成，不以单元测试代替真实用户流程验证。

## 全量范围

- [x] 角色行为：统一上下文；关系阶段、当前情绪与原因进入每轮对话；情绪惯性与恢复；只分析用户互动，避免助手自我加分。
- [x] 角色创作：表达方式、长度、主动程度、关系节奏、对话示例；预设差异；四语界面；新字段校验和持久化。
- [ ] 流式聊天：分句展示、停止、补发、长句兜底、重连恢复、刷新恢复、稳定消息标识、请求幂等。
- [ ] 生成结算：部分结果保存、取消与断线区分、多实例取消、并发限制、重试去重、额度与供应商实际用量分开。
- [ ] 记忆：会话摘要、语义召回、事实来源、更正失效、事件时间、跨角色隔离、上下文预算。
- [ ] 遗忘：删除/更正同时使索引、缓存和衍生摘要失效；暂停记忆、编辑和忘记入口。
- [ ] 主动陪伴：显式偏好、IANA 时区、免打扰、频率、事件驱动、忽略退避、发送前复查、推送与站内记录去重、隐私预览。
- [ ] 多模态：文字/语音/自拍共享角色上下文；语音播放取消；各媒体失败独立反馈、重试与结算。
- [ ] 运营：版本化提示词、任务用量/耗时、脱敏日志、可配置预算/超时/降级、功能开关、故障恢复与备份文档。
- [ ] 质量：真实业务回归、并发/失败/归属/重试测试、四语检查、浏览器验证、生产构建、逐项最终审计。

## 执行规则

保留 Express、tRPC、React、MySQL 和已有账户/配额基础。采用增量迁移，不重置应用数据库。不调用真实运营 AI、邮件或支付进行自动测试。独立 MySQL 测试库由现有脚本验证隔离和迁移。

运行时缺少技能所述 `protocol_request`、`agent_workspace_import` 和持久任务图工具，且 `.agents` 目录为只读，因此使用本仓库文档、可用协作消息、独立只读审查和 Git diff 代替该技能的协议/导入机制。

## 第一批契约：角色行为基础

交付：纯函数行为规则与有界上下文、关系/心情注入真实聊天路径、持久情绪原因与恢复、角色风格/示例输入、调用用量和耗时记录、增量迁移、针对实际函数/路由测试。

硬验收：

1. 不同关系阶段生成不同行为约束，保持原角色身份及既有回复语言和长度偏好。
2. 工作/生活负面表达不被简单视为对角色的攻击；助手文字不会改变情绪分数；长时间离线不触发惩罚。
3. 新字段能在创建、编辑、读取中往返，拒绝越界或超量示例；四个语言包完整。
4. 聊天调用引用当前角色状态及示例，设置的事实不能越过用户/角色归属；用户可控内容明确为资料而非平台指令。
5. 用量记录不包含正文或密钥，供应商缺失用量标为未知，不以零代替；失败不重复结算。
6. 检查、针对回归、完整测试和构建有明确结果；独立审查发现的问题修复后才提交。

### 第二批契约：流式聊天、打断与恢复

交付：服务端持久化聊天任务及分句结果；鉴权/CSRF 的流与取消接口；前端实时分句、停止、补发、刷新/断线恢复；稳定请求和消息标识；额度和供应商成本分离；并发/重试/多实例取消测试。

硬验收：

1. 相同客户端请求 ID 重试不会再创建任务或扣额度；用户、会话、角色归属和年龄检查均保留。
2. 完整句或长度/等待上限内展示片段；片段有持久 ID 和序号，刷新后能恢复原来分段和顺序。
3. 主动停止与网络断开区分；断开不直接取消上游，取消状态在数据库共享，旧结果不能覆盖新轮。
4. 用户补发时停止旧任务，旧片段保留，所有已接收补充出现在新上下文；多设备同会话并发不能形成两套结果。
5. 失败、部分结果、停止、成功有明确状态和可预测额度规则；多次结算或补偿不会重复计量。
6. 外部调用不持有数据库长事务；进程重启时过期任务可明确结束和补偿，不能无限显示生成中。
