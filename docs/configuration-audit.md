# 硬编码配置补查

本轮检查了种子导入、共享契约、前端控件与本地草稿、角色和会话持久化、提示词构造、生成与结算、语音、连接、调度和存储调用。现有业务值只作为新库初始数据导入，正式展示与执行读取发布配置，没有旧数据兼容分支。

| 本轮补齐的领域                                 | 统一来源和实际消费位置                                                                                  |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 角色默认行为、字段上限、示例数量、资料提示预算 | `characters`；创建、更新、编辑表单与提示词预览/执行                                                     |
| 新会话标题                                     | `characters.conversationTitle`；首次打开和显式新建统一在服务端生成，使用请求语言，模板仅允许 `{{name}}` |
| 情绪分数、恢复、变化幅度、展示门槛与多语言心情 | `emotion`；互动结算、聊天上下文和角色/聊天面板                                                          |
| 分页、最近角色、搜索长度与摘要                 | `experience.pagination`；API 默认分页、前端加载更多与展示                                               |
| 朗读速度、音调、音量和默认服务                 | `experience.playback`；菜单和实际浏览器朗读                                                             |
| 重试、轮询、请求超时和流观察间隔               | `experience.transport`；聊天请求、恢复和 SSE 观察                                                       |
| 最短录音、提示时长、运营统计窗口               | `experience`；录音提交、转写校验、统计执行和提示                                                        |
| 页脚说明及服务/支持链接                        | `site`；公开页和供应商设置入口；删除未使用的旧资源文案                                                  |
| 本地长消息草稿及待核对提交                     | 编辑使用 `runtime.chat.maxInputChars`；保存与恢复不再以 8000 字截断，待核对提交保留至请求协议容量       |
| S3 请求超时、签名有效期                        | `runtime.storage`；上传、读取、删除及签名链接实际调用                                                   |
| 记忆任务租约                                   | `memory.jobs.leaseMinimumMs` / `leasePaddingMs`；租约取最短租约与任务超时加余量的较大值                 |

首页最近角色移除了第二次固定数量裁剪；缺图会话使用普通占位，不再回退固定官方角色图片。所有配置可通过 [管理后台](management.md) 编辑，修改共享 schema 后表单字段随契约生成，提交仍进行完整校验。

## 保留在代码或部署环境的内容

以下是检查后保留的实现边界，未伪装成可运营的数据：

- UI 交互标签及翻译、产品标识、路由、布局和动画；这些随界面实现维护。
- 已支持的供应商、动作和行为枚举，HTTP/MIME/文件签名、模板变量以及数据库/请求协议容量。例如 `CHAT_INPUT_CAPACITY` 为可承载请求的结构上限，实际消息长度仍由 API 配置决定。
- 授权和归属校验、CSRF、加密、密码策略、管理会话与登录限流，以及固定官方 BYOK 端点；避免公开业务配置控制认证或凭据去向。
- 数据库和存储连接、邮件、公开部署地址、供应商凭据与签名密钥；由环境变量保管。
- 单位换算、排序与状态机、内容意图和日期识别算法，以及配置不可用时的调度恢复间隔。

初始值位于 `server/seeds/product.json` 和官方内容种子中。公开查询不会回退到种子，重复启动不覆盖已编辑的配置。当前开发阶段维护一份新库初始化基线，包含独立管理会话表。
