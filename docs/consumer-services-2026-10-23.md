# 隐私、订阅与售后服务补齐 · 2026-10-23

本轮接续 C 端走查中的 03、04 项，完成可操作的数据管理、订阅管理和站内售后流程。分支为 `codex/consumer-experience-fixes`。

## 用户可完成的操作

- `/privacy`：公开说明实际保存和第三方处理范围，登录后可下载个人数据、发起邮箱确认注销。未填写出生日期或尚未确认时区的账号也可进入这页管理数据。
- `/chats`：单独永久删除会话、其中的相册媒体及来源记忆；失效旧摘要和提取任务，阻止迟到结果复活。角色、其他会话和其他会话的输入草稿保留。
- 数据导出：下载 JSON，包含个人资料、角色、会话、记忆、偏好、私有音色参考、相册索引及自己的工单历史。排除密码、会话令牌和 BYOK 密钥字段。媒体以需登录访问的链接提供，文件本体须在注销前另行保存。
- 注销：先确认自动续费已取消，再向已验证邮箱发送十五分钟、单次使用的确认链接。打开链接只展示确认界面，还需输入账号邮箱和 `DELETE`。注销在同一事务中清理账号、全部设备会话、回收站角色、内容、密钥、任务与工单，媒体失败清理由后台重试。匿名进度凭据保留三十天，只返回是否仍有媒体待清理。
- 私人媒体：应用文件路由校验真实会话和资源归属；官方运营素材保持公开。注销后的排队文件立即停止通过应用路由提供，后台继续回收对象。已签发的对象存储链接、第三方处理记录和已下载副本不构成可即时撤回的本站数据。
- 设置中的订阅卡：显示状态、续费日期、套餐标价与付款异常。明确实际税费、折扣和续费金额以支付平台为准。已有未结束订阅不再显示再次购买按钮，转到支付平台管理套餐、续费、付款方式和账单。付款返回可再次核对权益，不把客户端“成功”参数当作付款证明。
- `/help`：游客可查看常见问题；登录后可提交、追问和查看售后工单，包括付款与退款申请。每账号每天最多新建五单、追问二十次。相同请求重试不重复建单，普通草稿按账号保留。退款由运营方在支付平台处理，工单提交不自动退款。
- `/admin/support`：独立管理会话下查看、回复、解决工单；用户追问会重新打开工单。回复保存在站内，用户需回到帮助页查看；当前不额外发送客服邮件。

## 部署要求

1. 本地运行库已核对旧迁移并应用本次新增表迁移，未修改现有账号内容。后续环境仍需按部署流程应用新增迁移 `0007_support_tickets.sql`（`pnpm db:migrate`）。它只增加工单表和索引，不修改现有用户内容。
2. 当前本地环境尚未配置支付 API Key，生产使用前需补齐。在线订阅管理需要服务端 `LEMONSQUEEZY_API_KEY`。点击时从固定的 Lemon Squeezy API 获取新的签名链接；不缓存或记录签名，不向客户端暴露 API Key。校验订阅 ID、客户 ID、支付邮箱和账号归属；信息不一致时关闭自动登录入口，通过付款收据或工单处理。
3. 继续配置现有 Webhook 和套餐 Variant ID。API 刷新与 Webhook 复用快照顺序及归属检查，不以页面回跳或付款按钮点击授予权益。
4. 配置现有 `ADMIN_PASSWORD`，安排运营方处理 `/admin/support`。未配置支付 API Key 时，前台明确提供收据与站内工单替代路径。
5. 注销确认使用现有认证邮件驱动；生产环境继续需要已配置的 SMTP 或 Resend。

签名管理入口与刷新方式依据 [Lemon Squeezy Customer Portal](https://docs.lemonsqueezy.com/guides/developer-guide/customer-portal)、[订阅读取 API](https://docs.lemonsqueezy.com/api/subscriptions/retrieve-subscription) 和 [订阅管理指南](https://docs.lemonsqueezy.com/guides/developer-guide/managing-subscriptions)。
