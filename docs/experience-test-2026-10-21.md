## 发现与修复

| 问题                                                           | 修复与复测                                                                                                                                     |
| -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 离开无录音聊天仍提示取消；取消等待挂起、迟到音频混入下一次录音 | 录音身份隔离、清理等待与回调，只有活动录音才提示；生命周期回归及部署后导航通过                                                                 |
| 长回复换行形成空白气泡                                         | 隐藏纯空白分段，保留完整正文及稳定编号；渲染回归与真实长故事页面通过                                                                           |
| “请更新记忆”未触发、猫名新旧并存                               | 明确更正请求触发提取，按唯一宠物身份更新原记录；多宠物歧义不擅自覆盖                                                                           |
| 真实模型的跨两句 quote 被静默过滤                              | 按完整来源句界处理连续摘录；拒绝保存、假设、转述及撤回不能通过只摘单句绕过；事实后独立追问仍可保存                                             |
| 旧会话忽略新回复语言                                           | 初始 system 加强仍未解决；用真实请求复放定位后，仅 DeepSeek 在当前 user 前重复语言设置，额外规则计入上下文预算；原会话英/日/韩实际流式回复通过 |
| 聊天搜索只查末条消息                                           | 改查同会话全部历史，保留账号隔离、分页、字面量转义和真正的末条预览；“西湖”页面命中旧对话                                                       |
| 完成后仍显示“正在重新连接”                                     | 接受有效快照后恢复连接状态，终态 EOF 和旧轮关闭不再触发重连；两个失败回归转绿，生成中补发并刷新实际通过                                        |
| 暂停时模型仍笼统声称记住                                       | 将角色/全局记忆开关传入提示词，说明仅当前对话参考；实际回复明确长期记忆未开启，后台确实未保存，恢复后跨会话不知道该内容                        |

每批代码均经独立只读审查。来源校验曾在审查中发现单句 quote 绕过和独立问句误拒，均补了提取及真实数据库提交回归后再通过。当前提示词版本为 `companion/1.4`、提取版本为 `memory-extract/3`。

## 真实模型与数据库

- 三角色同题共 9 次：小桃谈烘焙/草莓果酱，霧香谈散步/推理小说，夏未谈慢跑；表达可辨，均如实说明 AI 身份与初识关系。短回复首字约 0.66–1.68 秒；样本仅用于本轮体验验收。
- 重新清理合成角色的旧测试记忆后，原猫名记录 `id=5` 从团子更正为麻薯，`contentVersion=2`，来源指向真实用户消息 `66`；咖啡偏好来源 `58` 保留，未生成第二条猫名。
- 同角色新会话能回答麻薯与不加糖燕麦拿铁；夏未新会话回答不知道，未串角色。
- 手动改为栗子后新会话只回答栗子；删除猫名后不知道猫名但仍记得咖啡；全部遗忘后两者均不知道。旧原文与派生摘要未复活已遗忘事实。用户可见聊天记录仍保留，模型使用的历史按遗忘边界过滤。
- 暂停期间“青岚”“晨露”未进入记忆，重新开启后新会话不知道；开启后的“小满”和白茶正常形成有来源的新记录。
- Asia/Shanghai 下“明天我要参加陶艺课”保存为 `2026-10-22`、`planned`，绑定原始消息 `111`；未当作未知日期或历史日期。
- 提取成功以实际记录、版本、来源和跨会话回答共同验收，未把聊天中的口头承诺当作保存证明。

## 流式与界面

真实 DeepSeek HTTP/SSE 验证首片段后停止、相同任务刷新恢复、旧轮停止后补发新条件、断开观察连接后继续生成与保留前缀。浏览器再次执行长回复停止、生成中补发条件并立即刷新；旧内容保留，新条件生效，最终无持续重连提示或空白气泡。

桌面浏览器已走查：登录、退出后受保护页面跳转、重新登录、角色创建/昵称编辑/头像、软删除与回收站恢复、探索画风与关键词筛选/详情、聊天搜索、生成入口/姿势锁定、相册/原图、设置保存、四语界面、深色与主题刷新持久化、主动联系频率保存后关闭、隐私预览保持开启、通知空态。未配置语音凭据时不出现可执行的供应商预览；Lab 中 Fish/ElevenLabs 预览、失败提示、恢复重试均通过。

真实 ComfyUI：参考图约 14.8 秒、文生图约 9.3 秒、合照约 22.3 秒；真实图片文件、聊天消息、三条相册记录及大图查看均通过。输入与结果为成年 AI 角色测试资料。
