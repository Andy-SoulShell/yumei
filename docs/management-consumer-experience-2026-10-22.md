# 管理产品 C 端化走查 · 2026-10-22

本轮将管理后台从“切换分区的一页纸表单”改成“浏览内容与效果 → 选择具体对象或任务 → 就地编辑 → 预览、保存、发布”的产品流程，并沿用用户 Web 和 Mobile 的主题与材质。

## 页面主体

| 入口                           | 默认呈现                                       | 编辑方式                                                     |
| ------------------------------ | ---------------------------------------------- | ------------------------------------------------------------ |
| 官方角色                       | 可搜索的角色内容库、人物故事、身份与前台角色卡 | 名字与故事、封面与介绍、相处细节各自编辑；新增先填写必要资料 |
| 首页                           | 实际轮播、精选头像与排序、完整问答             | 点选单条轮播或问答编辑；推荐编排、展示偏好独立打开           |
| 主题                           | 带实际聊天效果的主题画廊、开放状态和默认主题   | 点选主题编辑颜色、文案，默认外观可直接操作                   |
| 套餐                           | 服务方式与套餐卡片、当前价格及权益             | 点选套餐编辑；订阅方式与请求频率按需打开                     |
| 自拍、关系、快捷表达           | 姿势、成长阶段和表达内容库                     | 选中具体条目编辑，创建与删除继续使用共享约束                 |
| 记忆、主动联系、心情、角色默认 | 当前容量、通知样例、心情和相处效果             | 从具体体验进入任务；关联设置可接着编辑同一草稿               |
| 模型、上传、运行、播放、页脚   | 当前服务、文件规则、执行预算和展示效果         | 服务卡片和任务入口按需编辑，默认页面不铺配置字段             |

18 个入口均有独立地址。角色示例为 `/admin/official/xiaotao`，主题为 `/admin/themes`，记忆为 `/admin/memory`。就地编辑地址例如 `/admin/themes?edit=appearance&item=sakura`，刷新可恢复同一对象，浏览器返回可关闭编辑器。无效角色地址显示找不到角色，避免误当成新建。

除角色库和套餐的搜索框外，默认内容页不显示配置输入框；关系试算保留为体验预览。关闭编辑器保留当前修改，返回页面即可看到效果；保存草稿和发布继续分开，相关配置仍作为完整快照保存。

## 问题与处理

| 级别 | 现象                                                   | 影响                         | 原因假设及定位                           | 修改                                                             |
| ---- | ------------------------------------------------------ | ---------------------------- | ---------------------------------------- | ---------------------------------------------------------------- |
| P0   | 320px 下角色切换框只剩箭头                             | 无法辨认正在编辑的角色       | 同一行的两侧按钮挤压了可伸缩选择框       | 手机选择框独占一行，保持 44px 高度                               |
| P0   | 新增编辑地址后，保存期间浏览器返回可能关闭编辑器       | 中断编辑上下文               | 路径保护未覆盖编辑查询参数               | 写入和后续草稿重读期间保留编辑器并恢复受保护地址                 |
| P1   | 各模块默认展开配置字段，用切换元素承担产品流程         | 必须理解配置结构才能完成任务 | 入口直接复用 schema 表单与任务 Tabs      | 改为内容库、人物档案、首页画布和效果预览，字段只在具体任务内出现 |
| P1   | 手机依赖 18 项下拉菜单，桌面功能藏在折叠分组中         | 寻找与切换成本高             | 导航未按用户端使用方式组织               | 分组侧栏、搜索抽屉、五项快捷底栏，共用同一入口定义               |
| P1   | 管理面板、状态与导航材质和用户端不一致                 | 跨端观感和层级割裂           | 自定义面板使用独立实色、边框与间距       | 复用语义主题、表面、玻璃和阴影变量，保留明暗与降低透明度回退     |
| P2   | 编辑卡片重复内边距、重复标题；长预览把操作推到屏幕下方 | 小屏阅读与操作距离过长       | 公共 Card 与页面重复留白，预览未渐进展开 | 去除重复留白，记忆先显示三阶段，增加首屏调整入口和服务卡片操作   |

## 样式约定

| 项目 | 使用值                                                                                                                 |
| ---- | ---------------------------------------------------------------------------------------------------------------------- |
| 字体 | 页面标题 24–30px / 1.3 / 650；内容标题 18–24px；正文 14px / 1.5；说明 12–13px                                          |
| 间距 | 4、8、12、16、20、24、28、32、48px，主要卡片统一 20–24px 留白                                                          |
| 栅格 | 页面最大 1680px，桌面侧栏 240px；900px 及以下使用手机导航；1280px 为宽屏任务布局断点                                   |
| 色彩 | `--background`、`--foreground`、`--primary`、`--muted-foreground`、`--glass-separator`，随现有主题变化                 |
| 材质 | `--surface-panel`、`--surface-field`、`--glass-toolbar-fill`、`--glass-panel-fill`、`--shadow-panel`、`--shadow-glass` |
| 圆角 | 控件 10–12px、内容卡 20px、首页开场与底栏 24px                                                                         |
| 触控 | 手机导航与主要操作至少 44px，抽屉搜索输入 16px；内容预留底栏和系统安全区                                               |

打开编辑器、选择菜单或抽屉时，后方页头、底栏和保存栏停止模糊；内容面板不逐张增加背景模糊。降低动态、降低透明度、高对比度继续使用现有回退约定。

## 直接改善

1. 把当前效果放在编辑字段之前，先看到要管理的内容。
2. 轮播与问答可按单条编辑，保留其他内容和译文。
3. 主题和服务使用可识别的效果卡片及明确操作。
4. 内容修改在返回预览后保留，保存、发布状态集中呈现。
5. 页面与编辑对象具备可恢复地址，手机切换沿用用户端导航习惯。
