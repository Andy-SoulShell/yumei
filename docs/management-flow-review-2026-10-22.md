# 管理后台 Web / Mobile 流程复查 · 2026-10-22

本轮发现主要残留在编辑入口内部：默认页已经是内容预览，但部分任务仍将整组字段或多份指令一起塞进弹窗。现改为“浏览具体内容 → 选择对象 → 编辑这一个对象 → 返回目录或效果预览”，保留原有完整草稿、校验和发布机制。

## 问题与处理

## 编辑与数据约束

- 目录页不自动展开配置字段；只保留搜索或必要的业务操作。
- 需要共同校验的少量字段保留在同一任务中，例如情绪分数区间、重试上下限、图片尺寸与容量。
- 数组路径的更新保持数组类型、原顺序与其他对象，不再将索引更新为普通对象；逐条编辑继续使用共享字段契约。
- 关系阶段、示例对话的新增与移除仍可完成；四种固定记忆类别只编辑展示名称。
- 返回目录保留未保存内容；保存后仍停留在对应对象。保存和草稿重读期间继续保护编辑地址和编辑器。
- 官方角色与首页一起发布，品牌、业务和系统设置作为完整快照独立发布。

## 视觉约定与直接改善

沿用用户端的语义颜色、面板和材质变量：`--background`、`--foreground`、`--primary`、`--surface-panel`、`--glass-separator`。目录卡片使用 20px 留白、20px 圆角、16px 间距；标题 14px、正文 14px / 24px，窄屏自动单列。

1. 指令卡片直接展示当前文稿摘要，不只显示配置名称。
2. 容量、积分和执行任务展示当前值与单位，先了解现状再编辑。
3. 新增轮播或问答后直接编辑新条目，保存后可继续打开同一条目。
4. 角色外貌、兴趣、称呼、相处方式、各语言文案及示例对话分别进入。
5. 主题保留完整明暗效果，退出具体编辑后继续在这个主题中查看效果。
