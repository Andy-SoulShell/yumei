# Admin 全页面表单与使用体验改造

目标：所有入口按业务任务组织，字段使用合适的表单控件，并明确单位、范围和实际生效含义。

## 第一批：字段控件与共享约束

- 全部数值字段显示单位、共享 schema 中的上下界、整数精度或调整步长；支持排除边界，例如 Top-p 必须大于 0。
- 时间可以切换毫秒、秒、分钟、小时和天；容量支持 B、KiB、MiB。切换只影响显示，不修改草稿，输入后换算回原存储单位。
- 免打扰使用本地时间选择，夜间奖励使用整点选择；颜色使用颜色选择器，比例、音量等提供滑块和数值输入。
- 上传格式、套餐语音服务采用多选；枚举采用选择控件并保留原值类型；地址采用 URL 输入，时区和币种提供候选。
- 字符数、列表数量与最小保留项按共享约束提示；空数值保留为无效输入，不自动变成 0，不允许保存。
- 区分 0、不限量、模型默认值、不使用奖励阈值等状态。语音奖励以时长、文字奖励以字符、连续互动以天、深入对话以轮计量。
- 官方角色年龄与排序、首页展示数量和轮播间隔共用相同控件；保存仍执行完整共享 schema 和服务端检查。

验证：字段单位覆盖与边界回归、真实 React 控件回归、原 Management 流程合计 3 个文件 28 项测试通过；TypeScript、相关 ESLint 通过。新增 8 项测试覆盖所有数值字段、精度换算、空值、排除边界、整天步长、免打扰时钟、最少格式数量及数字枚举类型。

## 第二批：全部设置页的任务与预览

13 个业务设置页全部接入任务分区、当前草稿效果预览和就地编辑，主题页保留明暗预览并增加配色、文案两个分区。

| 页面       | 对应操作体验                                                                         |
| ---------- | ------------------------------------------------------------------------------------ |
| 套餐与额度 | 套餐卡片、价格与权益编辑、复制为独立停用草稿、默认套餐按名称选择；复制不携带支付关联 |
| 自拍姿势   | 表情与名称卡片、解锁等级、画面与别名编辑、按名称选择有效默认姿势                     |
| 亲密度     | 等级阶梯与升级试算、具名奖励卡片、每日限制与本地夜间时段                             |
| 角色默认   | 默认相处方式、资料长度与提示预算分区，会话标题使用示例角色预览                       |
| 情绪       | 心情表情与颜色预览、具名样式卡片、分数与恢复、互动影响                               |
| 记忆       | 分类与各等级容量预览，提取、摘要、匹配、检索、任务独立分区                           |
| 主动联系   | 时区与免打扰时钟、联系间隔、通知样例、具名模板卡片与投递规则                         |
| 上传       | 分用途设置格式与容量，实时呈现用户上传规则；录音编码保留优先顺序                     |
| 模型       | 聊天、图片、语音及两种工作流分区；工作流支持节点 JSON 导入和具名节点选择             |
| 执行       | 聊天、图片、语音、内部任务、目录、存储和自动清理按场景编辑                           |
| 体验       | 朗读倍速与音量预览、分页搜索、录音反馈、连接和统计窗口分区                           |
| 提示词     | 快捷模板卡片、聊天、表达、图片、记忆和上下文预算，明确必需模板变量                   |
| 运营链接   | 实时页脚预览，公开说明和服务入口独立维护                                             |
| 主题       | 明暗预览、主题卡片、配色和文案分区；普通编辑保持主题标识                             |

通过现有 `ui:add` 使用的 shadcn 4.22.1 CLI 引入 Tabs、Slider、Field、Input Group 及其 Separator，保留已有 Input、Textarea、Button、Label 定制。枚举使用 Radix Select，时区、币种和长候选复用 Command / Popover 搜索选择，格式和权益复用 Checkbox，删除使用 AlertDialog。Slider 补全可访问名称；Input Group 将数值和单位放在同一控件内。

所有操作仍编辑同一份草稿：预览不发送模型或用户数据请求；切换任务保留未保存输入；非法工作流 JSON 在切换分区后仍保留，并阻止共享契约保存。套餐和姿势引用默认项时禁止直接删除，等级只允许从未被引用的末级删除，删除前有明确确认。

验证：新增 22 项回归，覆盖全部分区可达、契约字段无遗漏、卡片复制隔离、原支付映射保护、等级递增、有效默认引用、工作流错误保留与修复、上传规则实时预览，以及忙碌状态保护。管理相关及公共原子组件交互共 9 个文件 77 项通过；TypeScript、全项目 ESLint 与生产构建通过。下一批记录浏览器实际验收及发现问题的修正。
