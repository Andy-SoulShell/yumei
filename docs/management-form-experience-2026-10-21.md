# Admin 全页面表单与使用体验改造

目标：所有入口按业务任务组织，字段使用合适的表单控件，并明确单位、范围和实际生效含义。

## 第一批：字段控件与共享约束

- 全部数值字段显示单位、共享 schema 中的上下界、整数精度或调整步长；支持排除边界，例如 Top-p 必须大于 0。
- 时间可以切换毫秒、秒、分钟、小时和天；容量支持 B、KiB、MiB。切换只影响显示，不修改草稿，输入后换算回原存储单位。
- 免打扰使用本地时间选择，夜间奖励使用整点选择；颜色使用颜色选择器，比例、音量等提供滑块和数值输入。
- 上传格式、套餐语音服务采用多选；枚举采用选择控件并保留原值类型；地址采用 URL 输入，时区和币种提供候选。
- 字符数、列表数量与最小保留项按共享约束提示；空数值保留为无效输入，不自动变成 0，不允许保存。
- 区分 0、不限量、模型默认值、不使用奖励阈值等状态。语音奖励以时长、文字奖励以字符、连续互动以天、深入对话以轮计量。
- 官方角色年龄与排序、首页展示数量和轮播间隔共用相同控件；保存仍执行完整共享 schema 和服务端检查。

验证：字段单位覆盖与边界回归、真实 React 控件回归、原 Management 流程合计 3 个文件 28 项测试通过；TypeScript、相关 ESLint 通过。新增 8 项测试覆盖所有数值字段、精度换算、空值、排除边界、整天步长、免打扰时钟、最少格式数量及数字枚举类型。

所有操作仍编辑同一份草稿：预览不发送模型或用户数据请求；切换任务保留未保存输入；非法工作流 JSON 在切换分区后仍保留，并阻止共享契约保存。套餐和姿势引用默认项时禁止直接删除，等级只允许从未被引用的末级删除，删除前有明确确认。

## 第三批：浏览器验收与修正

使用独立测试库、本机生产构建和应用内浏览器操作，未更改现有开发数据库。桌面 1440×900、手机 390×844 均逐项访问 18 个管理入口、57 个设置任务分区，无横向溢出；同时检查浅色和深色下的实际呈现。

### 实测发现并修正

1. 图片额度：原先将未参与计量的另一周期显示为“不限量”，容易误判。改用按日、按月、不限量互斥单选，切换时同步更新两个底层字段，并保留已填数量。
2. 编辑上下文：切换任务或保存重读后会回到第一张卡片。分区、选中条目和搜索条件提升到管理工作台状态，保存完成及返回分区后继续编辑原对象；主题和具名规则同样保留选择。
3. 本地时间：原控件在实际浏览器的输入事件下只更新了显示，没有更新草稿。补充原生 input 事件处理，实测 23:15、07:45 保存为 1395、465 分钟，预览和前台设置一致。
4. 发布核对：变更值增加实际币种、时长、容量、比例及本地时间说明；套餐等数组按稳定标识比较，调序不再把整套内容误报为修改。
5. 精度与默认含义：整数存储单位按十进制精确换算，不将微小小数或指数输入四舍五入成合法值；较长时长选择合适的显示单位。主动联系的用户默认开启项保持只读关闭，并明确已有偏好与默认安排的适用范围。

## 后续核查：图片与文案编辑

用户反馈图片显示不全。原因是角色库、封面和轮播素材编辑使用固定尺寸的 object-cover，导致管理时看不到原图边缘。改为 object-contain；封面、通用图片字段和轮播素材提供原图弹窗，支持键盘关闭。前台预览仍使用真实卡片比例，并明确提示裁切与原图入口。

多语言字段改为按语言切换编辑，中文必填，其他语言空缺回退中文；切换语言保留同一对象中的其他翻译。回归覆盖翻译保留、空译文回退、原图弹窗源地址与 Escape 关闭；ConfigForm 10 项测试通过。浏览器验收将在语义流程改造完成后统一记录。
