# Admin 全页面表单与使用体验改造

目标：所有入口按业务任务组织，字段使用合适的表单控件，并明确单位、范围和实际生效含义。

## 第一批：字段控件与共享约束

- 全部数值字段显示单位、共享 schema 中的上下界、整数精度或调整步长；支持排除边界，例如 Top-p 必须大于 0。
- 时间可以切换毫秒、秒、分钟、小时和天；容量支持 B、KiB、MiB。切换只影响显示，不修改草稿，输入后换算回原存储单位。
- 免打扰使用本地时间选择，夜间奖励使用整点选择；颜色使用颜色选择器，比例、音量等提供滑块和数值输入。
- 上传格式、套餐语音服务采用多选；枚举采用选择控件并保留原值类型；地址采用 URL 输入，时区和币种提供候选。
- 字符数、列表数量与最小保留项按共享约束提示；空数值保留为无效输入，不自动变成 0，不允许保存。
- 区分 0、不限量、模型默认值、不使用奖励阈值等状态。语音奖励以时长、文字奖励以字符、连续互动以天、深入对话以轮计量。
- 官方角色年龄与排序、首页展示数量和轮播间隔共用相同控件；保存仍执行完整共享 schema 和服务端检查。

验证：字段单位覆盖与边界回归、真实 React 控件回归、原 Management 流程合计 3 个文件 28 项测试通过；TypeScript、相关 ESLint 通过。新增 8 项测试覆盖所有数值字段、精度换算、空值、排除边界、整天步长、免打扰时钟、最少格式数量及数字枚举类型。

后续批次将补充各设置页面的任务分区、内容卡片与效果预览，并记录浏览器验收。
