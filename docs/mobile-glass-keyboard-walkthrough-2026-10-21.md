# 手机端双模式：键盘、长聊天与玻璃叠加补查

本轮在 `main` 完成修复：键盘平移时输入区和浮层跟随可视区域，长聊天分页不再重复补偿，宽屏手机横放时继续使用紧凑聊天布局。

## 发现与修复

没有发现 P0 问题；本轮处理了以下影响阅读与操作连续性的 P1 问题。

| 问题                 | 现象与影响                                                                                       | 原因                                                              | 已完成的调整                                                                       |
| -------------------- | ------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 键盘平移             | 模拟可视区域高度 480px、顶部偏移 110px 时，角色栏仍在屏幕外，输入区下方留白 110px。              | 只监听高度变化，没有跟随 `visualViewport.offsetTop` 和 `scroll`。 | 根布局、弹窗、抽屉和顶部提示共用可视区域偏移；关闭或缩放后清理临时值。             |
| 重复底部安全区       | 键盘已经遮住主屏指示条，输入区仍可能额外保留底部安全区。                                         | 键盘状态下继续沿用屏幕底部安全区。                                | 键盘展开时将底部安全区归零，聊天输入仍保留 8px 自身间距。                          |
| 长聊天分页断层与跳动 | 恢复接口的旧终态轮次会显示在最近 50 条记录之前；加载更早消息也可能再次叠加浏览器已经补偿的距离。 | 流式快照没有遵循当前分页范围，滚动使用相对增量累加。              | 旧终态轮次随相应历史页合并；从加载前位置计算目标滚动值；切换会话后丢弃旧定位回调。 |
| 宽屏手机横放         | 932 × 430px 触摸屏出现桌面侧栏和两条顶栏，消息区只有 206px 高。                                  | 响应式布局只按 900px 宽度切换。                                   | 为触摸设备的低高度横屏聊天保留单条角色导航，消息区增加到 290px。                   |

另修复了键盘状态下提示被弹窗遮罩压住的问题：提示通过 Portal 独立挂载，可见提示保持可操作；关闭提示不会触发当前弹窗的外部点击关闭。

## 走查范围与结果

- 标准 / 实验模式，320 × 740、390 × 844、430 × 932px，共 6 组键盘布局检查。覆盖键盘高度改变、仅平移不改变高度、12 行草稿、底部安全区、历史阅读和关闭恢复；全部通过。
- 专用隔离数据库加入 120 条合成历史消息，通过实际分页接口检查两种模式从 50 条加载到 100 条、再到 122 条。正在阅读的原消息位置变化为 0px，初次进入仍定位到最新消息。
- 两种模式实测发送、真实 SSE 接口终态到达、生成期间继续编辑。阅读位置均保持在 `scrollTop=1800`，下一条草稿保留。上游回复来自本地模拟服务，SSE 终态被有意延后交付以检查阅读连续性。
- 手机横屏、聊天更多菜单 / 语速子菜单、亲密度抽屉均补查。额外通过直接导入真实公共组件的临时检查页，验证键盘上方的弹窗内选择器、侧边抽屉与顶部提示。该检查页没有加入产品路由。

## 玻璃叠加与舒适度判断

标准模式继续使用稳定的消息底色和实色菜单。实验模式的导航、输入区和浮层保持既有材质：子菜单打开后，父菜单及后方聊天导航停止模糊，只有最上层子菜单保留 20px 模糊；聊天气泡不增加独立模糊层。两种模式的菜单文字与操作入口均可辨认。

本轮没有继续提高透明度。键盘展开后可用空间变少，维持文字底色、减少重复导航和保住阅读位置更直接影响长聊天舒适度。模拟检查中输入区没有遮住末条消息，浮层没有落到键盘后，纵向滚动保留在消息区域。

| 参数 / 规则                          | 用途                                                                 |
| ------------------------------------ | -------------------------------------------------------------------- |
| `--keyboard-viewport-height`         | 可视区域高度，关闭键盘和捏合缩放时移除。                             |
| `--keyboard-viewport-top`            | 可视区域顶部偏移，监听可视区域 `resize` 与 `scroll`，负值按 0 处理。 |

| 触摸设备、宽度 ≥ 901px、高度 ≤ 500px | 横屏聊天隐藏全局顶栏与桌面侧栏。                                     |
