日期：2026-10-23。范围：角色选择、快速创建、聊天、图片任务与作品、设置、记忆管理。

## 验收口径

界面语言、AI 回复语言和用户内容分别处理。界面切换不会翻译或覆盖已有名字、人设、对话示例、聊天记录、场景描述或记忆。发布的角色标签、介绍和业务状态使用对应语言。供应商、模型标识及通用缩写保持其原始名称。

浏览器检查使用独立的临时 MySQL、合成账号、本地聊天与 ComfyUI 协议夹具。未修改日常开发数据库，未调用真实付费生图或聊天服务。图片夹具只返回占位图片，用于验证任务生命周期、页面状态与交互；不评估模型画质。验收库提高了连续生图的频率上限，以便连续执行四种语言；套餐额度及原周期结算规则未改变。

基础页面检查保留 PWA Service Worker。WebKit 的模型搜索补查使用浏览器响应夹具，并在该临时浏览器中停用 Service Worker，以便拦截模型目录请求；验证的是下拉搜索、触控尺寸和焦点行为，不代表真实供应商目录已经验收。

## 核心旅程

| 旅程       | 中 / 英 / 日 / 韩的检查内容                                                                                                |
| ---------- | -------------------------------------------------------------------------------------------------------------------------- |
| 角色选择   | 首页、搜索筛选、详情、触控入口；添加后进入聊天，再次选择恢复同一会话，不重复添加。                                         |
| 创建       | 提前展示容量，进阶选项初始收起，展开后可读；实际创建后直接进入聊天，会话标题沿用当前语言。                                 |
| 聊天       | 发送与流式回复；手机回车换行；输入法确认不发送；可用高度收缩时输入区保持可见；未发送草稿保留。                             |
| 生图与作品 | 明确请求触发排队；生成、完成和失败状态；离页与刷新恢复同一任务；失败显示原周期返还说明；连续重试及刷新只提交一次上游任务。 |
| 设置       | 常用与高级分区、保存范围；保存中、成功、失败与重试；失败保留输入，保存和语言选择刷新后保持；搜索选择、Escape 与焦点返回。  |
| 记忆       | 分类、搜索、取消删除、核对更正、失败后重试；影响说明与成功反馈；返回来源会话，保留原聊天草稿。                             |

## 验证结果与复现

- Chromium 与 WebKit 均检查四种语言，覆盖 390×844 和 320×568；另检查 320×320 的可用高度收缩场景。
- 每个引擎每种语言检查 20 个页面状态，共 160 个基础状态，涵盖首页、角色详情、探索、快速和高级创建、聊天、记忆确认、作品入口及设置各分区。修复后补查生图弹窗、原生筛选、搜索选择和键盘操作。
- 44 组补充流程、254 项浏览器断言通过；最终基础状态与补充流程的布局检查均无剩余问题。
- 真实浏览器交互验证四种语言的创建、会话衔接、设置保存失败与重试、记忆更正失败与重试、图片任务恢复与结算提示。上游提交计数确认恢复不重复提交、一次失败的重复重试只创建一个新任务。
- 自动检查翻译键及插值、横向溢出、被裁切的按钮、可见触控区域；并人工查看长英文、日韩换行、生图弹窗、记忆确认和保存失败截图。
- `pnpm test:acceptance`：41 个文件、460 项测试通过，无需数据库。包含四种语言的会话参数、自拍意图识别、界面翻译、保存与记忆操作，以及输入与键盘回归。
- 隔离测试数据库的完整回归：187 个文件、1633 项测试通过。
- TypeScript、ESLint、Prettier、生产构建及 diff 空白检查通过。

浏览器截图位于本机 `output/playwright/i18n-*`，机器检查记录位于忽略目录 `tmp/setup-flow-lab/`，最终汇总为 `multilingual-final-report.json`。这些临时验收产物不进入源码版本库。验收后关闭专用浏览器和服务，移除临时数据库与账号凭据；保留原有开发服务。

本轮验证浏览器手机视口与模拟可用区域收缩，尚未覆盖 iOS / Android 真机系统键盘、系统原生菜单和触觉反馈；发布前仍需真机走查。语音录制权限、真实 AI 服务质量和真实支付链路不属于本轮验收范围。
