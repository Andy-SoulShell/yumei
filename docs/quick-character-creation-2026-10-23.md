# 快速创建、渐进定制与聊天衔接

日期：2026-10-23。接续首页与角色详情优化，对应[界面与用户体验要求](界面与用户体验要求.md)中的第二批工作。

## 用户体验

- 创建页先显示实际剩余角色名额，区分读取中、读取失败、有限名额、名额已满和不限量。读取失败可重试；满额提供角色管理入口。关闭计费执行时，与服务端一致按不限量处理。
- 预设选择默认显示四位，更多角色分批展开；写实／动漫筛选切换后恢复紧凑列表。选定预设后收起列表并显示形象缩略图和身份。异步载入的预设进入同样的紧凑状态。
- 快速创建只需预设或上传参考图、名字与性格。预设自动带入资料；上传自定义形象时，外貌描述可以留空，实际提交使用「外貌以参考图为准」。
- 「形象与兴趣」「相处方式」「角色声音」分别展开，高级提示词沿用独立折叠。首次打开声音前不加载该分区；再次折叠保留已编辑内容和本地输入。无效的高级资料会自动展开对应分区供修正。
- 创建按钮关联原表单并保持在滚动区域底部，避免被长表单的起点或浮动导航挡住；主要操作和名字输入至少 44px。保留原表单校验、草稿恢复和预设覆盖确认。
- 成功创建后直接恢复或创建该角色的会话，并以替换当前历史的方式进入聊天，避免浏览器返回到刚提交的表单。
- 如果角色保存成功、聊天暂时打不开，显示「已创建」和聊天重试入口。当前标签页保存已创建角色标识，刷新或离开后返回可继续；只重试打开会话，不再次创建角色。退出登录清理这些本机记录。
- 已保存的上传文件会释放，不在聊天打开失败后继续提示「未保存图片」。较早请求完成时，不清理新登录会话的草稿，也不把旧聊天导航带到其他账号。
- 编辑已有角色保留原有保存、头像、删除与返回角色管理的行为。

## 验证

- 创建专项：`pnpm test:setup`，5 个文件、62 项通过，覆盖快速表单、渐进展开与输入保留、实际名额、关闭计费、无效高级字段、草稿、重复提交、聊天失败重试、刷新恢复和跨登录会话结果隔离。
- 探索专项 9 个文件、75 项通过，中英日韩本地化专项 5 个文件、38 项通过；部分角色名额用例在专项之间共享，不重复相加。TypeScript、全仓 ESLint、Prettier、差异空白检查及生产构建通过，保留已有的大分块和第三方注释提示。
- Playwright 检查 390×844、320×844、320×450 和 1440×900。手机为浏览器视口模拟，未当作 iOS／安卓真机验收。
- 隔离的合成 Plus 账号初始为 1 个角色、上限 3 个；创建前显示剩余 2 个，预设创建后直接进入聊天，后端确认高级兴趣值正确保存。
- 同一账号上传仓库内的虚构成年角色图片，仅填写名字、性格完成自定义创建，外貌描述未额外填写。人为中断 `conversation.resume`，确认显示「角色已保存」及重试入口；恢复后后端核对该自定义角色只有 1 份、对应会话只有 1 个。
- 达到 3 个角色后，创建页提前显示满额并提供管理入口，不再提供创建提交按钮。
- 预设加载、查看更多、切换画风、默认已选中的「从零自定义」、高级字段折叠保留，以及新建会话中的角色名和输入区均检查。
- 英文 320×450 下检查无横向溢出、提交按钮位于浮动导航上方、触控高度及表单关联。走查中发现并修正了短视口操作栏受长表单起点限制的问题。
- 最终操作栏调整后，再次通过关联表单提交真实创建并进入新会话，确认没有因按钮移到表单外而丢失校验或提交行为。

测试环境使用独立浏览器会话、全新临时 MySQL 容器和本地 SMTP／服务夹具。原通用 Lab 的回环地址、已有测试凭据和结账夹具不适用于本机当前环境，因此用忽略目录下的脚本副本启动本轮专用检查；未把未跑通的通用 HTTP smoke 计作通过。套餐由隔离库中的合成订阅记录提供，不代表真实购买验收。人为注入的网络失败会产生预期错误日志；其他实际页面检查未发现脚本异常。

本轮未改动正式账号、已发布业务配置或真实支付数据。临时测试环境在验收后关闭；本地开发站点继续使用当前源码。
