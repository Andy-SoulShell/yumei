# 设置页任务分组与保存反馈

日期：2026-10-23。

## 本轮改动

设置页按用户任务组织，常用设置先出现：聊天方式、声音与朗读、界面与外观。随后是提醒与时区、套餐与用量、账号与隐私。六个快捷入口可以定位并展开对应分区。默认展开聊天方式，高级服务默认收起，其中聊天模型、图片服务、语音转文字、个人密钥分别展开。

聊天方式先展示回复语言和长度，自定义提示词与模板按需展开；声音先展示本设备自动朗读，再展开音色与试听；外观先展示语言和明暗，主题与实验材质折叠。折叠只隐藏已访问的表单，继续保留其输入；首次访问才挂载子分区，目录请求只在相应任务展开且服务可用时发起。

## 保存范围

| 任务       | 生效方式与范围                                                           |
| ---------- | ------------------------------------------------------------------------ |
| 聊天方式   | 显式保存本分区的回复语言、长度和聊天偏好，作用于账号所有角色             |
| 声音与朗读 | 声音和本分区个人密钥保存到账号；自动朗读仅本设备立即生效                 |
| 界面与外观 | 界面语言、明暗、主题自动同步账号；实验材质仅本设备立即生效               |
| 提醒与时区 | 主动联系、时区、免打扰显式保存到账号；设备推送单独开关，仅影响当前浏览器 |
| 套餐与用量 | 查看与管理订阅，无设置保存动作，交易以服务确认结果为准                   |
| 账号与隐私 | 资料、密码各自保存；导出、注销保持各自独立流程                           |
| 高级服务   | 模型、图片、转写各自保存本分区；移除已保存密钥立即生效                   |

移除“保存全部”，避免只保存部分设置却让用户误以为全页已保存。每个手动保存分区提供未修改、未保存、保存中、成功、失败和部分成功状态；失败保留输入并提供重试。结果留在原分区，辅助技术通过 status / alert 读取。

提交时固定本次偏好与密钥快照。请求期间继续编辑的新内容不会被成功回包清除；部分成功后只重试仍未完成的字段。重复点击不会启动第二批写入。普通草稿继续按账号保存在当前会话中，密钥仅保留在内存中；切换账号、退出或卸载页面后，旧请求不能继续写后续密钥或回填新账号。

保存成功但读取状态失败会单独说明，并提供重新读取，不把已成功的写入报告为失败。外观自动保存增加持久的成功反馈，保留同步失败和重试入口；主动联系补充就地保存中、成功反馈。设备推送补充不支持、未配置、读取失败、授权拒绝及操作结果，服务工作线程未就绪时不会无限等待。

## 手机体验

快捷入口三列布局，分区整行可展开。主要按钮、表单控件和折叠入口至少 44px；开关扩大触摸区域，输入文字在小屏采用 16px，减少 Safari 聚焦放大。分区按钮允许换行，长服务名称、说明和保存状态不挤出窄屏。沿用应用底栏的滚动留白，不新增覆盖内容的全页保存栏。

设置锚点支持直接打开对应分区；原有 `#privacy` 和注销验证链接继续打开账号与隐私，不提前丢弃验证片段。
